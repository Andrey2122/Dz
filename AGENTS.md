# Правила проекта

## Язык

- Отвечать пользователю на русском языке.
- Комментарии в коде — на английском, если в файле уже нет русских комментариев.

## Ежедневник (правило «запиши в ежедневник»)

**Триггер:** пользователь пишет фразу «запиши в ежедневник» (или близкую по смыслу) сразу после полученного ответа.

**Действие:** дописать в файл `ЕЖЕДНЕВНИК.md` (корень проекта) новый блок с вопросом и ответом из последнего обмена.

**Формат новой записи:**

```markdown
<details>
<summary><b>В: <вопрос пользователя></b></summary>

**О:** <сжатый ответ с ключевым кодом>

</details>
```

Раздел с темой оформляется жирным названием темы:

```markdown
## <дата> | Тема: **<название темы>**
```

**Обязательные правила:**

1. Только добавление в конец файла. Существующие записи не изменять, не перемещать, не удалять.
2. Если тема новой записи совпадает с уже существующим разделом `## <дата> | Тема: ...` этого дня — добавить блок внутрь этого раздела. Если темы нет — создать новый раздел с текущей датой и жирным названием темы.
3. Вопрос всегда внутри `<summary>` и обёрнут в `<b>`, ответ — внутри блока `<details>`. Каждый блок `<details>` обязательно закрывать тегом `</details>`.
4. Ответ в ежедневнике — сжатая версия: ключевые примеры кода и вывод, без длинных объяснений и таблиц.
5. Перед записью прочитать `ЕЖЕДНЕВНИК.md` и дописывать через точечную замену в конце файла, а не полной перезаписью.
6. После записи подтвердить пользователю одной строкой, что запись добавлена.
7. Если файла `ЕЖЕДНЕВНИК.md` нет — создать его с заголовком `# Ежедневник Java` и подсказкой о сворачивании, затем добавить запись.
