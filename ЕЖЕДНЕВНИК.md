## 2026-10-19 | Тема: **Массивы**

<details>
<summary><b>В: Как заполнять массив с помощью random</b></summary>

**О:** Три основных способа:

1. **Класс `Random`**
```java
Random rand = new Random();
int[] arr = new int[10];
for (int i = 0; i < arr.length; i++) {
    arr[i] = rand.nextInt(100); // 0..99
}
```

2. **`Math.random()`**
```java
int[] arr = new int[10];
for (int i = 0; i < arr.length; i++) {
    arr[i] = (int) (Math.random() * 100); // 0..99
}
```

3. **Java Streams**
```java
int[] arr = new Random().ints(10, 0, 100).toArray();
```

</details>

<details>
<summary><b>В: Как находить минимальное и максимальное значение массива</b></summary>

**О:** Три основных способа:

1. **Цикл (учебный)**
```java
int min = arr[0];
int max = arr[0];
for (int num : arr) {
    if (num < min) min = num;
    if (num > max) max = num;
}
```

2. **`Arrays.stream()`**
```java
int min = Arrays.stream(arr).min().getAsInt();
int max = Arrays.stream(arr).max().getAsInt();
```

3. **`Collections` для `List<Integer>`**
```java
int min = Collections.min(list);
int max = Collections.max(list);
```

</details>

int sum = Arrays.stream(arr).sum();

double avg = (double) sum / arr.length;

<details>
<summary><b>В: Как посчитать медиану — отсортировать массив и взять средний элемент</b></summary>

**О:** Сортируем копию массива и берём средний элемент (для чётной длины — среднее двух средних):

```java
int[] sorted = arr.clone();   // копия, чтобы не менять исходный массив
Arrays.sort(sorted);

double median;
if (sorted.length % 2 == 1) {
    median = sorted[sorted.length / 2];              // 5 -> индекс 2
} else {
    int mid = sorted.length / 2;
    median = (sorted[mid - 1] + sorted[mid]) / 2.0;  // 4 -> (1+2)/2
}
```

Через Stream (одной строкой):
```java
double median = Arrays.stream(arr).sorted().asDoubleStream()
    .skip((arr.length - 1) / 2L)
    .limit(2 - arr.length % 2)
    .average().orElse(0);
```

Вывод для `[42, 17, 89, 3, 55, 71, 28, 64, 9]`:
```
СОРТИРОВКА = [3, 9, 17, 28, 42, 55, 64, 71, 89]
МЕДИАНА = 42.0
```

Важно: `sum / arr.length` — целочисленное деление, для среднего нужно `(double) sum / arr.length`.

## 2026-10-20 | Тема: **switch(choice)**

<details>
<summary><b>В: Как работает switch(choice)</b></summary>

**О:** `switch` — «переключатель»: берёт одно значение и выбирает один из нескольких блоков (`case`).

**Классический синтаксис:**
```java
switch (choice) {
    case 1:
        // добавить задачу
        tasks += "\n" + (++count) + ". " + scanner.nextLine();
        break;
    case 2:
        // показать все задачи
        System.out.println(count == 0 ? "Список пуст" : tasks);
        break;
    case 3:
        System.out.println("До свидания!");
        break;
    default:
        System.out.println("Неверный выбор: " + choice);
}
```

**Механика:**
1. Вычисляется выражение `choice` (один раз)
2. Java сравнивает результат с каждым `case` сверху вниз (`==`)
3. Найден совпавший `case` → выполнение продолжается с этой строки
4. `break` → выход из switch. Без `break` — «проваливание» (fall-through) в следующий case
5. Если совпадений нет → `default`

**Ловушки:**
- Забыл `break` → выполняется код всех последующих case
- Забыл `scanner.nextLine()` после `nextInt()` → пустая задача
- `switch` принимает `int`, `String`, `enum`. `long`, `double`, `boolean` — ошибка

**Стрелочная форма (Java 14+):**
```java
switch (choice) {
    case 1 -> tasks += "\n" + (++count) + ". " + scanner.nextLine();
    case 2 -> System.out.println(count == 0 ? "Список пуст" : tasks);
    case 3 -> System.out.println("До свидания!");
    default -> System.out.println("Неверный выбор");
}
```
`break` не нужен, проваливания нет.

**В цикле меню:**
```java
int choice;
do {
    System.out.println("\n=== ЧЕК-ЛИСТ ===\n1. Добавить\n2. Показать\n3. Выйти");
    choice = scanner.nextInt();
    switch (choice) { /* действия */ }
} while (choice != 3);
```

</details>
